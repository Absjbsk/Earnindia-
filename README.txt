EARN INDIA - STARTER PWA

Included:
- Responsive Hindi/English landing page
- Demo dashboard and sample offer cards
- Copyable SAMPLE links
- PWA manifest, service worker and app icon

IMPORTANT:
This is a front-end prototype only. It does NOT have real user accounts,
affiliate attribution, a database, commission verification, withdrawals,
or payment processing. Sample links use example.com and do not earn money.
Do not collect passwords, bank details, UPI PINs, OTPs, or identity documents
in this prototype.

To test:
1. Upload these files to a static HTTPS host (for example GitHub Pages).
2. Open the HTTPS website in Chrome on Android.
3. Use the browser menu > Install app / Add to Home screen.
4. PWA install requires HTTPS (localhost is also suitable for development).

Before real launch:
- Join legitimate affiliate programs and check their current eligibility,
  age, tax, disclosure and payout rules.
- Replace sample links only with approved affiliate URLs.
- Build secure backend authentication and verified click/conversion tracking.
- Add a privacy policy, terms, contact details and clear affiliate disclosures.
- Never promise guaranteed earnings or charge users to join.
